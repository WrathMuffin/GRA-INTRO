Tutorial 2: Fundamentals Shaders
Within this is the Unity project for challenges 2 and 4. There are two cubes in the project that uses 2 types of shaders. One cube uses the blending shader which blends two textures (and optionaly a color) which is controlled by a float blend value, and the other uses color addition which blends a texture with a color.
