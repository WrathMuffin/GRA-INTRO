Intro to computer graphics

TUT - tutorial stuff

Tutorial 2: Fundamentals Shaders
Within this is the Unity project for challenges 2 and 4. There are two cubes in the project that uses 2 types of shaders. One cube uses the blending shader which blends two textures (and optionaly a color) which is controlled by a float blend value, and the other uses color addition which blends a texture with a color.

Tutorial 4: Illumination models
Within the scene assets, there is a scene called Tut 4 for this activity. There is an object called the Bol, which has the shader Tut 4 Activity, attached to material also called Tut 4 Activity. In the material properties within the inspector, there is a drop down list of 3 lighting types: Lambert, Ambient, and Specular.
